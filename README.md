# ModularCV

Un CV online dinámico y actualizable que evoluciona con tus logros en tiempo real.

## Características

- **Actualización automática**: Sincroniza tus repositorios de GitHub, credenciales de Google Drive, perfil de LinkedIn
- **UI limpia y moderna**: Diseño profundo, magnético, sin distracciones visuales
- **Modo Desarrollador**: Interfaz oculta para configurar sincronizaciones (acceso solo para ti)
